# Pr1_bank_operations

Приложение для анализа банковских операций из Excel-файла.

## Описание

Это приложение обрабатывает данные о банковских транзакциях из файла `operations.xlsx`,
предоставляет JSON-данные для веб-страниц, формирует Excel-отчеты
и предлагает дополнительные сервисы.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <ваш_репозиторий>
   cd Pr1_bank_operations
   ```
2. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
   ```
3. Активируйте виртуальное окружение:
   ```bash
   poetry shell
   ```
4. Создайте файл `.env` на основе `.env_template` и заполните необходимые API ключи:
   ```
   CURRENCY_API_KEY=ваша_ключ_для_валют
   STOCK_API_KEY=ваша_ключ_для_акций
   ```
5. Поместите файл `operations.xlsx` с данными о транзакциях в папку `data/`.

## Использование

Для запуска основных функций приложения используйте `main.py`.
Примеры использования будут добавлены по мере реализации функционала.
